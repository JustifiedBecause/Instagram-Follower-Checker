# Instagram-Follower-Checker
Python script to parse and process downloaded Instagram follower data
Subject to break at anytime, Meta often makes breaking changes to their data structures

Modes:
1. Not Following Back
Parses your Followers and Following lists, and tells you which users appear in your following, but not followers. I.E. You follow them but they don't follow you.
This list will include users with deactivated accounts

2. Pending Requests
Returns a list of pending requests and how many days it's been since you sent the request
